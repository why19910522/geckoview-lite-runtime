## 实际移除与保留边界

**移除：** `CrashReporter`、`CrashHandler`、`CrashPullController`、`CrashHelper`、`ICrashHelper` 的 Java/AIDL 产物；helper Manifest 服务；`libcrashhelper.so`、`libcrashtools.so`；CrashSubmit/CrashReports/CrashService/CrashManager/RemoteSettingsCrashPull/ChildCrashHandler JS，以及 reporter 页面和专用本地化资源。

AIDL 的 exclude 配置未能阻止 AGP 生成接口类，因此产品补丁实际删除 `ICrashHelper.aidl`，清理本变体 Java/AIDL 输出后重新编译。其他 AIDL 仍用于媒体、编辑器和子进程通信，保持启用。

未捕获异常转交 Android 当前默认处理器，保留堆栈文本；没有安装新的 reporter。定向探针调用实际抽取的方法，验证原始 Throwable 与当前线程只委派一次。设置非空 crash handler 会明确抛出 `UnsupportedOperationException`；此 AAR 不再提供上述 reporter 类及 Runtime CrashPull 委派方法，接入方需要移除相应引用。

通用 `CrashMonitor` / `nsCrashMonitor` 用于启动和异常退出状态，不是报告采集/上传后端，保留；native 使用上游无 reporter 的必要空实现。普通子进程、媒体、安全边界未因本轮裁剪关闭。

**Lite 的实际范围：** 此固定上游修订的开关主要改变 Maven 能力声明及 artifactId；源码搜索和构建配置表明它没有完全移除 Glean，本次 `MOZ_GLEAN_ANDROID` 仍开启。不将“Lite=true”表述为 Glean/遥测已经全部裁掉。

## 中文资源与单语言打包

原构建只有 en-US；直接设置 zh-CN 时发现以下真实问题并解决：

1. 普通非英文源码资源任务没有传递 l10n base，JarMaker 的 localedirs 为 None。产品补丁为直接源码构建使用固定翻译目录，语言 repack 仍可覆盖 merge 目录。
2. Android 的 locales 规则使用 merge-dir，先执行官方 `merge-zh-CN` 生成它。
3. `multilocale.txt` 生成器及 installer 强制追加 en-US。产品补丁使用配置的 UI locale，仅注册显式语言；默认 en-US 输入行为的定向验证保持通过。
4. Gradle 默认 `machBuildFaster` 的 FasterMake 后端硬编码 AB_CD=en-US，在本次非英文构建中失败。完整 native、Java/JNI、中文 misc/libs 与 stage-package 先单独完成，最后用上游 `IS_LANGUAGE_REPACK=1` 模式发布 AAR，防止它再次覆盖已生成的中文资源；未关闭 AAR 元数据检查。

最终 omni.ja 核对：`localization/` 只有 zh-CN；所有 chrome locale 注册均为 zh-CN；`res/multilocale.txt`、`default.locale` 均仅为 zh-CN；没有 en-US chrome/localization 语言目录。实际 commonDialogs 资源含“确定”“取消”等中文，未以重命名英文目录冒充翻译。

“仅中文”指 UI 本地化包；网页 `Intl`、Unicode/字符集和任意语言网页内容能力保留。上游固定文本、诊断文本及未进入本地化流程的预览文本不承诺全部汉化。

## 可复现步骤与成功证据

补丁应用需要 `patch -E -p1 --fuzz=0`，其中 `-E` 确保 BSD patch 也会真正删除 ICrashHelper.aidl，而非留下空 AIDL。17 个受影响路径（含 1 个删除文件）均已从原始输入零模糊度重放，与实际构建源码一致。

环境准备、固定翻译修订和详细命令见[中文构建说明](../../localization/README.md)、[构建配置](../../build-config/README.md)。在源码根目录、产品环境中依序执行：

```sh
python mach configure
python mach build pre-export
python mach build export
python mach build binaries
python mach build merge-zh-CN
python mach build misc
python mach build libs
python mach build stage-package
IS_LANGUAGE_REPACK=1 python mach gradle \
  geckoview:checkDebugAarMetadata geckoview:assembleDebug \
  geckoview:publishDebugPublicationToMavenRepository
```

上述 python 必须使用项目固定的 Python 3.12.14 / uv 0.13.0 环境。完整 native 从独立空对象目录实际编译，耗时约 10 分 51 秒；后续清理 Java/AIDL、重建绑定并再次 native 检查通过。成功日志仅保留本机 `artifacts/logs/lite-zh-cn-*`。
