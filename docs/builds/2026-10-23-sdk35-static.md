## 按真实失败确定的调整

| 实际失败 | 处理 | 能力影响与验证 |
| --- | --- | --- |
| 上游 configure 查找 `android-37.2`，API 35 专用 SDK 无此目录 | 平台参数改为 35/0、target 30；整数平台使用 `android-35` 路径 | configure 通过；不改变 minSdk 26 |
| 光标闪烁方法有 4 个 API 35 缺失符号 | 保留 JNI 签名，返回原有 500 ms 默认值 | 不读取 Android 36.1 系统光标闪烁偏好；定向 javac、完整 Java/JNI 编译通过 |
| SessionAccessibility 有 3 个 API 36 缺失符号 | 删除节点 required-field 上报，使用已有 boolean checked 回退 | 基础无障碍保留；新版必填和部分选中属性不上报；完整 Java/JNI 编译通过 |
| Core 1.19.1 AAR 要求 minCompileSdk 37 | 仅 GeckoView 模块固定 Core 1.16.0 | 该版本 AAR 声明 minCompileSdk 35；GeckoView 与独立宿主元数据检查通过 |
| Media3 1.11.1 的 8 个 AAR 要求 minCompileSdk 36 | 为既有 HLS 条件编译路径增加 `--disable-android-hls`，本次关闭 | 移除原生 HLS/Media3 集成；其他媒体路径保留；未实测媒体播放 |
| 无关 Maven 仓库的 HEAD 超时使整个仓库被 Gradle 禁用 | 给官方构建依赖仓库添加坐标组过滤 | 保留原有仓库与版本选择，不修改信任、TLS 或 AAR 元数据；不涉及内核分发渠道 |

API 边界参考 [Android AccessibilityNodeInfo](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo)、[Core 发布记录](https://developer.android.com/jetpack/androidx/releases/core)。实际失败日志和 AAR 元数据是本次裁剪依据；没有把其他可选模块一并删除。

## 已执行的产品构建闭包

在固定源码根目录设置本机环境并应用补丁后：

```sh
mise x python@3.12.14 uv@0.13.0 -- python mach configure
mise x python@3.12.14 uv@0.13.0 -- python mach build binaries
mise x python@3.12.14 uv@0.13.0 -- python mach gradle \
  geckoview:checkDebugAarMetadata \
  geckoview:assembleDebug \
  geckoview:publishDebugPublicationToMavenRepository
```

三个步骤均退出 0。`binaries` 是完整 native 目标；先前的总构建已实际编译 C++/Rust 并链接 `libxul.so`，最终 `binaries` 检查为增量通过。未以下载预编译 Gecko 内核替代编译。保留上游 bootstrap 的编译器、工具和第三方依赖获取机制。

本地 Maven 输出为 `$GECKO_OBJDIR/gradle/maven`，准确坐标：

```text
org.mozilla.geckoview:geckoview-default-omni:160.0.20261023103723-SNAPSHOT
```

随后用[独立宿主](../../smoke-host/README.md)通过上游 wrapper 执行 `:app:assembleDebug`，退出 0（35 个任务执行）。它不依赖上游 Gradle project substitution，`org.mozilla.geckoview` 独占解析到本次本地 Maven 目录。运行时依赖报告确认 Core 1.16.0，没有 Media3 依赖；未抑制 AAR 元数据检查。

**总构建限制：** `mach build` 退出 2，发生在 native 完成后的 `messaging_example:checkDebugAarMetadata`，其 Core/Core KTX 1.19.1 要求 API 37。上游聚合归档还包括 AndroidTest、test_runner 和多个示例。本轮保留这些源码和校验，改用上述库构建目标与独立宿主验证产品闭包；没有宣称总构建、上游示例或测试套件通过。

原始日志仅在本地 `artifacts/logs/` 保存：`build-sdk35-attempt7.log`（总构建失败）、`native-sdk35-binaries.log`、`aar-sdk35-publication.log`、`smoke-sdk35-attempt1.log`、`smoke-runtime-dependencies.log`、`apk-zipalign-sdk35.log`、`apk-signature-sdk35.log`。工具下载曾有超时重试；native 编译有警告，包括本机 Rust objcopy 缺少 libLLVM 的非致命调试信息剥离警告，未按零警告构建报告。
